# Canary privacy policy

Canary is a synthetic application used to validate the ClaimCheck tool chain. It does not use any third-party
analytics providers. All data is processed locally.

## What the application handles
The application keeps its working files on your own computer. It does not create an account for you and it does not
ask for your name, your e-mail address or any other personal detail. Nothing you type is transmitted to a server that
we operate, and we never sell or share your files with anyone.

## Network access
The only network activity you should expect is the optional check for a new release, which contacts the project's own
website. If you use the application behind a proxy, the same proxy settings apply to that check.

## Changes to this policy
When this document changes, the new version is published together with the release notes.
